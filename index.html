📘 Эталонный пример

Ориентир

Изучи этот код. Он показывает, как создавать окно, Label, поле ввода, кнопки и связывать их с функциями. На него можно ориентироваться при решении всех задач.

💡 Что важно запомнить:
1. tkinter.Tk() — создаём окно.
2. tkinter.Label(...), tkinter.Entry(...), tkinter.Button(...) — создаём виджеты.
3. .place(x=..., y=...) — размещаем их в окне.
4. command=имя_функции — БЕЗ скобок! Иначе функция вызовется сразу.
5. mainloop() — запускаем окно в конце. 
import tkinter

# Создаём окно программы
master = tkinter.Tk()
master.title('Оконное приложение')
master.geometry('300x250')

# Создаём Label и размещаем его
label = tkinter.Label(text='Я Label')
label.place(x=20, y=20)

# Специальная переменная для хранения значения поля ввода
entry_var = tkinter.StringVar()

# Создаём поле ввода
entry1 = tkinter.Entry(textvariable=entry_var, width=40)
entry1.place(x=20, y=60)

# Кнопка 1 — изменить текст Label
def btn1click():
    label['text'] = 'Здравствуй мир!'

btn1 = tkinter.Button(text='Изменить Label', command=btn1click)
btn1.place(x=20, y=100)

# Кнопка 2 — задать значение в поле ввода
def btn2click():
    entry_var.set('Новое значение')

btn2 = tkinter.Button(text='Задать значение Entry', command=btn2click)
btn2.place(x=20, y=140)

# Кнопка 3 — прочитать значение поля ввода и показать в Label
def btn3click():
    label['text'] = entry_var.get()

btn3 = tkinter.Button(text='Прочитать значение Entry', command=btn3click)
btn3.place(x=20, y=180)

# Запускаем окно
master.mainloop()

Уровень 1

Создайте оконное приложение со счётчиком. При клике на кнопку значение Label должно увеличиваться на единицу.

Цель: каждое нажатие — +1 к числу на экране. Начни с 1.
GIF недоступен (нет интернета или ссылка недоступна). Смотри описание задачи выше.
Подсказка

Тебе нужна глобальная переменная для хранения значения.

Внутри функции не забудь написать global value, иначе Python будет считать, что ты создаёшь новую локальную переменную, и выдаст ошибку.

Цель: после клика содержимое первого поля оказывается во втором, и наоборот.
GIF недоступен. Смотри описание задачи выше.
Подсказка

Тебе нужны две переменные StringVar() — по одной на каждое поле.

Внутри функции сначала сохрани значение первого поля в отдельную переменную (val1 = var1.get()), потом перезапиши первое вторым, а затем запиши сохранённое во второе.

Цель: генерация N полей ввода по числу N. Перед пересозданием — удалить старые через .destroy().

3. Сначала удали старые: пройди по списку и вызови у каждого i.destroy(), потом очисти список (entry_list = []).

4. Считай число из поля через int(var1.get()).

5. В цикле for i in range(count) создавай tkinter.Entry(width=5), вычисляй left = 20 + i * 40 и вызывай .place(x=left, y=60).

6. Не забудь entry_list.append(x), иначе при следующем клике не сможешь удалить поля.

Задача 4. Генератор матрицы

Уровень 3

Разместите 2 поля ввода (строки и столбцы) и кнопку. По умолчанию — 0. При клике генерируется матрица из полей ввода. Повторный клик пересоздаёт матрицу, удаляя старую.

Цель: вложенный цикл по строкам и столбцам, позиционирование по сетке.
GIF недоступен. Смотри описание задачи выше.
Подсказка

1. Два StringVar(): lines и cols. Оба .set(0).

2. Внутри btn1click очисти entry_list так же, как в задаче 3.

3. Считай: lines_val = int(lines.get()), cols_val = int(cols.get()).

4. Двойной цикл: внешний по i in range(lines_val), внутренний по j in range(cols_val).

5. top = 100 + i * 20 — сдвиг по вертикали (по строкам). left = 20 + j * 40 — сдвиг по горизонтали (по столбцам).

6. Не забудь entry_list.append(x).

Задача 4.1. Сплошная нумерация

Уровень 3

Доработайте задачу 4: каждое сгенерированное поле должно содержать свой номер, начиная с 1.

Цель: добавить в матрицу счётчик и StringVar для каждого поля.
GIF недоступен. Смотри описание задачи выше.
Подсказка

1. Заведи второй список: entry_vars = [] — туда будешь складывать StringVar'ы.

2. Перед циклами: counter = 0.

3. Во внутреннем цикле: counter += 1, создай entry_var = tkinter.StringVar(), затем entry_var.set(counter).

4. Передай textvariable=entry_var в tkinter.Entry(...).

5. entry_vars.append(entry_var) — понадобится в задачах 4.2 и 4.3.

6. Не забудь в начале функции очистить и entry_vars: объяви global entry_vars и entry_vars = [].

Задача 4.2. Сдвиг влево

Уровень 3

Добавьте кнопку «Влево». При клике значение каждого поля перемещается в предыдущее. Значение из первого поля уходит в последнее.

Цель: циклический сдвиг значений по кругу влево.
GIF недоступен. Смотри описание задачи выше.
Подсказка

1. Сначала проверь: если len(entry_vars) == 0 — return (матрица ещё не сгенерирована).

2. Сохрани первое значение: first = entry_vars[0].get().

3. Пройди циклом for i in range(1, len(entry_vars)) и присвой entry_vars[i-1].set(entry_vars[i].get()).

4. В последнее поле запиши сохранённое первое: entry_vars[-1].set(first).

Задача 4.3. Сдвиг вправо

Уровень 3

Добавьте кнопку «Вправо». Значения сдвигаются вправо, последнее значение переходит в первое.

Цель: циклический сдвиг значений вправо.
GIF недоступен. Смотри описание задачи выше.
Подсказка

1. Снова проверь пустоту: if len(entry_vars) == 0: return.

2. Сохрани последнее значение: last = entry_vars[-1].get().

3. Иди циклом с конца в начало: for i in range(len(entry_vars) - 1, 0, -1) и присвой entry_vars[i].set(entry_vars[i-1].get()).

4. В первое поле запиши сохранённое: entry_vars[0].set(last).

5. Важно: если идти с начала, ты затрёшь значения, которые ещё не сдвинул. Поэтому — только с конца!
